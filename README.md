# 🛍️ SkyStore - Интернет-магазин передовой техники

## 📋 Описание проекта

SkyStore - это веб-приложение на Django для продажи плагинов, примеров кода и цифровых товаров. Проект разрабатывается в
рамках учебного курса с целью изучения фреймворка Django и основ веб-разработки.

### 🎯 Цели проекта

- Изучение основ Django framework
- Практика работы с шаблонами и Bootstrap
- Реализация обработки форм и POST-запросов
- Создание кастомных страниц ошибок
- Работа с моделями и базами данных (PostgreSQL)
- Настройка административной панели
- Работа с фикстурами и кастомными командами
- Создание динамических страниц товаров
- Перевод контроллеров с FBV на CBV
- Создание блога с полным CRUD
- Реализация CRUD для продуктов с валидацией форм
- Аутентификация пользователей (регистрация, вход, выход)
- Ограничение доступа к CRUD операциям
- Модерация продуктов и управление правами
- Кеширование с Redis для ускорения работы

## 🚀 Функциональность

### Каталог товаров

- ✅ Главная страница с карточками товаров (CBV - ListView)
- ✅ Детальная страница товара (CBV - DetailView)
- ✅ Обрезанное описание (100 символов)
- ✅ Адаптивный дизайн на Bootstrap
- ✅ CRUD для продуктов(Create, Read, Update, Delete)
- ✅ Валидация форм(запрещенные слова, отрицательная цена, формат изображения)
- ✅ Ограничение доступа - CRUD только для авторизованных пользователей
- ✅ Модерация продуктов (группа "Модератор продуктов")

### Блог

- ✅ Полный CRUD для блоговых записей (Create, Read, Update, Delete)
- ✅ Все контроллеры на CBV (ListView, DetailView, CreateView, UpdateView, DeleteView)
- ✅ Счетчик просмотров статей (увеличивается при открытии)
- ✅ Фильтрация - отображаются только опубликованные статьи
- ✅ Перенаправление на страницу статьи после редактирования
- ✅ Группа "Контент-менеджер" для управления блогом

### Общие функции

- ✅ Страница контактов с формой обратной связи
- ✅ Обработка POST-запросов с выводом в консоль
- ✅ Кастомные страницы ошибок 404 и 500
- ✅ Базовый шаблон (base.html) и подшаблоны
- ✅ Модели Category и Product
- ✅ Админ-панель с настройкой отображения
- ✅ Фикстуры для экспорта/импорта данных
- ✅ Кастомная команда `load_test_data`

### Аутентификация и пользователи

- ✅ Кастомная модель пользователя (наследуется от AbstractUser)
- ✅ Email как идентификатор для входа (USERNAME_FIELD)
- ✅ Дополнительные поля: аватар, телефон, страна
- ✅ Регистрация с подтверждением пароля
- ✅ Отправка приветственного письма после регистрации
- ✅ Авторизация по email и паролю
- ✅ Редактирование профиля пользователя

### Система ролей и прав

- ✅ Группа "Модератор продуктов" - может публиковать/снимать с публикации и удалять любые товары
- ✅ Группа "Контент-менеджер" - может управлять блогом (создание, редактирование, удаление статей)
- ✅ Право `can_unpublish_product` - отмена публикации продукта
- ✅ Проверка прав в контроллерах и шаблонах

### Кеширование с Redis

- ✅ Настройка Redis как брокера кеширования
- ✅ Кеширование страниц товаров (TTL: 1 час)
- ✅ Кеширование списка товаров в категории (TTL: 30 минут)
- ✅ Низкоуровневое кеширование всех товаров (TTL: 10 минут)
- ✅ Сервис ProductService для работы с кешем
- ✅ Автоматическая очистка кеша при обновлении/удалении товара
- ✅ Кеширование всего сайта через middleware

## 📦 Установка и запуск

### 1. Клонируйте репозиторий:

```
git@github.com:HapkoM01/Django---.git

cd sky_store
```

### 2. Создание виртуального окружения:

#### Windows:

```
python -m venv venv
venv\Scripts\activate
```

#### Mac/Linux:

```
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

```
Создайте файл .env в корне проекта:

# PostgreSQL настройки
DB_NAME=sky_store_db
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

# Django настройки
SECRET_KEY=your-secret-key-here
DEBUG=True
```

### 5. Создание базы данных PostgreSQL

```
CREATE DATABASE sky_store_db;
CREATE USER sky_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE sky_store_db TO sky_user;
```

### 6. Применение миграций

```
python manage.py makemigrations
python manage.py migrate
```

### 7. Создание групп и прав

```
python manage.py create_groups
```

### 8. Создание суперпользователя

```
python manage.py createsuperuser
```

### 9. Загрузка тестовых данных

```
python manage.py load_test_data
```

### 10. Запуск сервера

```
python manage.py runserver
```

### 11. Открыть в браузере'

```
http://127.0.0.1:8000
```

### Проверка валидации формы

``` 
Попробуйте создать товар с:

▶ Отрицательной ценой → ошибка

▶ Запрещенным словом "казино" → ошибка

▶ Изображением >5 МБ → ошибка
```

### Проверка ограничения доступа

```
Без авторизации:
▶ Создание товара (/products/create/) → перенаправление на /users/login/
▶ Редактирование товара → перенаправление на /users/login/
▶ Удаление товара → перенаправление на /users/login/
```
