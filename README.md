# 🛍️ SkyStore - Интернет-магазин плагинов и кода

## 📋 Описание проекта

SkyStore - это веб-приложение на Django для продажи плагинов, примеров кода и цифровых товаров. Проект разрабатывается в
рамках учебного курса с целью изучения фреймворка Django и основ веб-разработки.

### 🎯 Цели проекта

- Изучение основ Django framework
- Практика работы с шаблонами и Bootstrap
- Реализация обработки форм и POST-запросов
- Создание кастомных страниц ошибок
- Работа с моделями и базами данных (PostgreSQL)
- Настройка административной панели
- Работа с фикстурами и кастомными командами

## 🛠 Технологии

| Технология | Версия | Назначение |

| Python | 3.8+ | Язык программирования |

## 🚀 Функциональность

✅ Главная страница с карточками товаров

✅ Страница контактов с формой обратной связи

## 📦 Установка и запуск

### 1. Клонируйте репозиторий:

```
git@github.com:HapkoM01/Django---.git

cd sky_store
```

### 2. Создание виртуального окружения:

#### Windows:

```
python -m venv venv
venv\Scripts\activate
```

#### Mac/Linux:

```
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

```
Создайте файл .env в корне проекта:

# PostgreSQL настройки
DB_NAME=sky_store_db
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432

# Django настройки
SECRET_KEY=your-secret-key-here
DEBUG=True
```

### 5. Создание базы данных PostgreSQL

```
CREATE DATABASE sky_store_db;
CREATE USER sky_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE sky_store_db TO sky_user;
```

### 6. Применение миграций

```
python manage.py migrate
```

### 7. Запуск сервера

```
python manage.py runserver
```

### 8. Открыть в браузере

```
http://127.0.0.1:8000
```

### 9. Запуск и проверка

```
👉🏻 Выполните миграции
python manage.py migrate

👉🏻 Создайте суперпользователя (для админки)
python manage.py createsuperuser

👉🏻 Запустите сервер
python manage.py runserver
```

## 📱 Тестирование

### Проверка работы приложения

#### 1. Главная страница

```
Откройте http://127.0.0.1:8000/

Проверьте отображение 4-х карточек товаров

Убедитесь в наличии хедера и футера
```

#### 2. Страница контактов

```
Перейдите по ссылке "Контакты" или откройте http://127.0.0.1:8000/contacts/

Проверьте наличие формы обратной связи
```

#### 3. POST-запрос

```
Заполните форму на странице контактов

Нажмите "Отправить"

Проверьте консоль сервера - должны появиться введенные данные

```

#### Пример вывода в консоли:

```

=====================================
=== Получены данные из POST-запроса ===
Имя: Иван Петров
Телефон: +7 (999) 123-45-67
Сообщение: Хочу узнать подробнее о товаре
=====================================
```

#### 4. Ошибка 404

```
Откройте любую несуществующую страницу, например http://127.0.0.1:8000/test

Для просмотра кастомной 404:

Временно измените в settings.py: DEBUG = False

Добавьте: ALLOWED_HOSTS = ['127.0.0.1', 'localhost']

Перезапустите сервер

После проверки верните DEBUG = True
```
